Wofür ist das?

Alle Daten von KASSIVO stehen in einer einzigen Datenbankdatei. Eine Sicherung ist eine vollständige Kopie davon. Sie brauchen sie, wenn eine Änderung schiefgeht, der Rechner ausfällt oder Sie umziehen.

So geht's

Sicherung erstellen

  1. Öffnen Sie Backup (/backup).
  2. Wählen Sie „Sicherung erstellen“.
  3. KASSIVO meldet „Sicherung erstellt:“ mit dem Dateinamen. Die Datei liegt im Ordner backups neben der Datenbank (<DB-Ordner>/backups). Den genauen Pfad zeigt KASSIVO beim Start in der Zeile „Sicherungen:“.
  4. Die Liste „Vorhandene Sicherungen“ zeigt Datei, Zeitpunkt und Größe.

Wiederherstellung (von Hand)

In KASSIVO gibt es keinen Knopf zum Zurückspielen. Gehen Sie so vor:

  1. Beenden Sie KASSIVO.
  2. Kopieren oder benennen Sie die aktuelle kassivo.db im DB-Ordner um, damit sie nicht verloren geht.
  3. Löschen Sie eine eventuell vorhandene Datei kassivo.db-journal neben der Datenbank. Sonst könnte ein altes journal auf die wiederhergestellte Kopie angewendet werden.
  4. Kopieren Sie die gewünschte Sicherung aus <DB-Ordner>/backups als kassivo.db in den DB-Ordner.
  5. Starten Sie KASSIVO und prüfen Sie die Daten.

Beispiele

Beispiel: Am 24.11.2026 um 14:05:30 Uhr erstellen Sie eine Sicherung. Die Datei heißt kassivo-20261124-140530.db. Erstellen Sie in derselben Sekunde noch eine, heißt sie kassivo-20261124-140530-2.db. KASSIVO überschreibt nie eine vorhandene Sicherung.

Gut zu wissen

  • Auf Knopfdruck. Im normalen Betrieb sichert KASSIVO nicht von selbst. Legen Sie eine Sicherung vor größeren Schritten an, zum Beispiel nach dem ersten Import oder vor „Regeln anwenden“ mit Überschreiben.
  • Datenbankformat: Vor Änderungen am Datenbankformat legt KASSIVO automatisch eine Sicherung an (Dateiname beginnt mit kassivo-, wie jede Sicherung); eine Datenbank aus einer neueren Version wird nicht geöffnet. Die Seite Backup zeigt unten die Schema-Version der Datenbank und des Programms. Versionen bis 1.1.1 prüfen die Schema-Version nicht. Kehren Sie deshalb nach einem Update nicht mit derselben Datenbank zu einer älteren KASSIVO-Version zurück, und legen Sie vor jedem Update eine Sicherung an.
  • Aufräumen: KASSIVO löscht nie Sicherungen. Alte Dateien löschen Sie selbst im Ordner. Die Liste zeigt die 50 neuesten.
  • Stand der Daten: Eine wiederhergestellte Sicherung enthält nur, was bis zu ihrer Erstellung eingetragen war. Spätere Änderungen und Importe fehlen. Importieren Sie die Kontoexporte erneut. Bereits vorhandene Buchungen erkennt KASSIVO als Duplikate.
  • Personenbezogene Daten: Eine Sicherung enthält Namen, Adressen und IBANs. Legen Sie sie nicht in einen Cloud-Ordner (OneDrive, Dropbox, Google Drive, iCloud) und geben Sie sie nicht weiter. Beim Start warnt KASSIVO, wenn die Datenbank (und damit der Sicherungsordner) in einem solchen Ordner liegt.
  • Bewahren Sie wichtige Sicherungen zusätzlich auf einem anderen Datenträger auf, denn der Sicherungsordner liegt auf demselben Rechner wie die Datenbank.

Achtung: Kopieren Sie niemals eine Sicherung über die Datenbank, solange KASSIVO läuft, und ersetzen Sie kassivo.db nur nach Schritt 2 (aktuelle Datei zuerst wegkopieren).
