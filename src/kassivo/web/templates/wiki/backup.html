Wofür ist das?

Alle Daten von KASSIVO stehen in einer einzigen Datenbankdatei. Eine Sicherung ist eine vollständige Kopie davon. Sie brauchen sie, wenn eine Änderung schiefgeht, der Rechner ausfällt, Sie umziehen oder abwechselnd an zwei PCs arbeiten (zum Beispiel Arbeits-PC und Heim-PC).

So geht's

Sicherung erstellen

  1. Öffnen Sie Backup (/backup).
  2. Wählen Sie „Sicherung erstellen“.
  3. KASSIVO meldet „Sicherung erstellt:“ mit dem Dateinamen. Die Datei liegt im Ordner backups neben der Datenbank (<DB-Ordner>/backups). Den genauen Pfad zeigt KASSIVO beim Start in der Zeile „Sicherungen:“.
  4. Die Liste „Vorhandene Sicherungen“ zeigt Datei, Zeitpunkt und Größe.

Für anderen PC exportieren

  1. Wählen Sie auf Backup „Für anderen PC exportieren“.
  2. Der Browser lädt eine Datei kassivo-backup-JJJJMMTT-HHMMSS.kassivo herunter. Sie enthält die ganze Datenbank und eine Beschreibung (Programmversion, Schema-Version, Erstellzeit, Prüfsumme).
  3. Bringen Sie die Datei auf den anderen PC, am besten per USB-Stick. Löschen Sie sie danach.

Sicherung einspielen

  1. Wählen Sie auf Backup unter „Sicherung einspielen“ die .kassivo-Datei und dann „Datei prüfen“. Für eine Sicherung aus der Liste „Vorhandene Sicherungen“ wählen Sie stattdessen „Wiederherstellen“ in ihrer Zeile.
  2. KASSIVO prüft die Datei: Archiv, Prüfsumme, Unversehrtheit der Datenbank und Schema-Version. Ist etwas nicht in Ordnung, meldet KASSIVO den Grund und spielt nichts ein.
  3. Die Vorschau zeigt die Eckdaten der Sicherung (Erstellt, Programmversion, Schema, Mitglieder, Buchungen, letzte Buchung) neben denen der aktuellen Datenbank. Prüfen Sie, dass der eingespielte Stand der neuere ist.
  4. Setzen Sie den Haken „Ich bestätige, dass die aktuelle Datenbank ersetzt wird“ und wählen Sie „Sicherung einspielen“.
  5. KASSIVO legt zuerst eine Sicherheitskopie der aktuellen Datenbank im Ordner backups an, ersetzt dann die Datenbank in einem Schritt und meldet „Sicherung eingespielt“ mit dem Namen der Sicherheitskopie. Ein Neustart ist nicht nötig.

Wiederherstellung (von Hand)

Nur nötig, wenn KASSIVO nicht mehr startet. Gehen Sie so vor:

  1. Beenden Sie KASSIVO.
  2. Kopieren oder benennen Sie die aktuelle kassivo.db im DB-Ordner um, damit sie nicht verloren geht.
  3. Löschen Sie eine eventuell vorhandene Datei kassivo.db-journal neben der Datenbank. Sonst könnte ein altes journal auf die wiederhergestellte Kopie angewendet werden.
  4. Kopieren Sie die gewünschte Sicherung aus <DB-Ordner>/backups als kassivo.db in den DB-Ordner.
  5. Starten Sie KASSIVO und prüfen Sie die Daten.

Beispiele

Beispiel: Am 24.11.2026 um 14:05:30 Uhr erstellen Sie eine Sicherung. Die Datei heißt kassivo-20261124-140530.db. Erstellen Sie in derselben Sekunde noch eine, heißt sie kassivo-20261124-140530-2.db. KASSIVO überschreibt nie eine vorhandene Sicherung.

Gut zu wissen

  • Auf Knopfdruck. Im normalen Betrieb sichert KASSIVO nicht von selbst. Legen Sie eine Sicherung vor größeren Schritten an, zum Beispiel nach dem ersten Import oder vor „Regeln anwenden“ mit Überschreiben.
  • Datenbankformat: Vor Änderungen am Datenbankformat legt KASSIVO automatisch eine Sicherung an (Dateiname beginnt mit kassivo-, wie jede Sicherung); eine Datenbank aus einer neueren Version wird nicht geöffnet. Die Seite Backup zeigt unten die Schema-Version der Datenbank und des Programms. Versionen bis 1.1.1 prüfen die Schema-Version nicht. Kehren Sie deshalb nach einem Update nicht mit derselben Datenbank zu einer älteren KASSIVO-Version zurück, und legen Sie vor jedem Update eine Sicherung an.
  • Aufräumen: KASSIVO löscht nie von selbst. Auf der Seite Backup können Sie unter „Alte Sicherungen aufräumen“ die neuesten Sicherungen (1 bis 1000, voreingestellt 10) behalten und alle älteren löschen. Dafür setzen Sie den Haken „Ich bestätige, dass ältere Sicherungen gelöscht werden“. Die neueste Sicherung bleibt immer erhalten. Das Löschen ist nicht rückgängig zu machen. Es betrifft nur Dateien mit dem Namen einer Sicherung (kassivo-…db), andere Dateien im Ordner bleiben unberührt. Die Liste zeigt die 50 neuesten. Die Reihenfolge richtet sich nach dem Zeitstempel im Dateinamen (Ortszeit). Bei der Umstellung auf die Winterzeit kann ein älter wirkender Name der neuere sein. Behalten Sie dann einige Sicherungen mehr.
  • Dauerhaft gespeichert: KASSIVO schreibt die Sicherung erst vollständig auf den Datenträger und gibt sie dann unter ihrem Namen frei. Ein Stromausfall mitten im Sichern hinterlässt keine halbe Sicherung unter einem gültigen Namen. Es kann aber eine leere Datei mit gültigem Namen oder eine Datei .kassivo-…tmp übrig bleiben. Leere Dateien werden nie aufgelistet oder mitgezählt, die .tmp-Reste können Sie von Hand löschen. Nach dem Erstellen lädt die Seite neu, ein Neuladen im Browser legt keine zweite Sicherung an.
  • Stand der Daten: Eine wiederhergestellte Sicherung enthält nur, was bis zu ihrer Erstellung eingetragen war. Spätere Änderungen und Importe fehlen. Importieren Sie die Kontoexporte erneut. Bereits vorhandene Buchungen erkennt KASSIVO als Duplikate.
  • Versionen: Eine Sicherung aus einer älteren KASSIVO-Version stellt KASSIVO beim Einspielen auf das aktuelle Datenbankformat um und sichert den eingespielten Stand vorher. Eine Sicherung aus einer neueren Version lehnt KASSIVO ab. Aktualisieren Sie dann zuerst KASSIVO auf diesem PC.
  • Kein Zusammenführen: Haben Sie auf beiden PCs seit dem letzten Abgleich gearbeitet, ersetzt der eingespielte Stand den aktuellen vollständig. Die Änderungen des anderen Stands stecken dann nur noch in der Sicherheitskopie.
  • Geöffnete Datenbank: Hat ein anderes Programm oder ein zweites KASSIVO-Fenster die Datenbank geöffnet, ersetzt KASSIVO nichts und meldet das. Die geprüfte Datei liegt bis zum Einspielen oder zur nächsten Prüfung im Ordner restore neben der Datenbank.
  • Personenbezogene Daten: Eine Sicherung enthält Namen, Adressen und IBANs. Auch die .kassivo-Datei ist nicht verschlüsselt. Legen Sie sie nicht in einen Cloud-Ordner (OneDrive, Dropbox, Google Drive, iCloud) und geben Sie sie nicht weiter. Beim Start warnt KASSIVO, wenn die Datenbank (und damit der Sicherungsordner) in einem solchen Ordner liegt.
  • Bewahren Sie wichtige Sicherungen zusätzlich auf einem anderen Datenträger auf, denn der Sicherungsordner liegt auf demselben Rechner wie die Datenbank.

Achtung: Spielen Sie Sicherungen über „Sicherung einspielen“ ein. Kopieren Sie niemals von Hand eine Sicherung über die Datenbank, solange KASSIVO läuft, und ersetzen Sie kassivo.db von Hand nur nach Schritt 2 (aktuelle Datei zuerst wegkopieren).
