Wofür ist das?

Damit KASSIVO weiß, wer bezahlt hat, muss jeder Zahlungseingang einem Mitglied zugeordnet sein. Das geschieht automatisch, wenn die Absender-IBAN eindeutig bekannt ist. Alles andere landet in der Liste Unklar (/unmatched) und wird von Hand zugeordnet. Ausgaben werden nie Mitgliedern zugeordnet.

Wann ordnet KASSIVO selbst zu?

KASSIVO ordnet neue Zahlungseingänge beim Import zu (und wenn Sie „Unklare automatisch zuordnen“ wählen), wenn alle diese Bedingungen stimmen:

  • Die Zahlung hat eine Absender-IBAN.
  • Die IBAN ist KASSIVO bekannt: Entweder haben Sie sie früher mit „Absender merken“ einem Mitglied zugeordnet, oder sie steht im Datensatz des Mitglieds (Feld „IBAN“). Eine gemerkte IBAN hat Vorrang.
  • Die IBAN gehört genau einem Mitglied. Gehört sie mehreren, ist sie mehrdeutig und die Zahlung bleibt in „Unklar“.
  • Das Mitglied ist nicht vor der Zahlung ausgetreten. Liegt die Zahlung nach dem Austrittsdatum, bleibt sie in „Unklar“.

Danach setzt KASSIVO die Kategorie „Beiträge“, falls die Buchung noch keine Kategorie hat, und berechnet die Verteilung (siehe Verteilung auf Beitragsmonate).

So geht's

Eine Zahlung zuordnen

  1. Öffnen Sie Unklar. Dort stehen Datum, Gegenpartei, Zweck und Betrag jeder offenen Zahlung.
  2. Wählen Sie rechts in „Mitglied zuordnen“ das Mitglied.
  3. Lassen Sie „Absender merken“ angehakt, wenn dieser Absender künftig automatisch zu diesem Mitglied gehören soll.
  4. Wählen Sie „Zuordnen“. KASSIVO zeigt einen Hinweis und ordnet gleich alle weiteren Zahlungen derselben IBAN in „Unklar“ mit zu.
  5. Prüfen Sie danach die Offene Vorschläge und bestätigen Sie sie.

Unklare automatisch zuordnen

Der Knopf „Unklare automatisch zuordnen“ oben in „Unklar“ wendet gemerkte IBANs und die IBANs der Mitglieder noch einmal auf die ganze Liste an. Das hilft, nachdem Sie eine IBAN im Mitgliedsdatensatz ergänzt haben. KASSIVO meldet, wie viele Zahlungen zugeordnet wurden.

Zuordnung ändern oder entfernen

  1. Öffnen Sie Buchungen und suchen Sie die Zahlung (Filter oder Suche helfen).
  2. Wählen Sie in der Spalte „Mitglied“ ein anderes Mitglied oder „— keins —“ und dann „Zuordnen“. Mit „— keins —“ steht die Zahlung wieder in „Unklar“. Sie bleibt dort nur, bis KASSIVO sie wieder zuordnet (siehe „Achtung“ unten).
  3. Meldet KASSIVO „… hat bestätigte Verteilung: Verteilung zuerst aufheben“, öffnen Sie über „Verteilung“ die Verteilungsseite, haken Sie „Ich bestätige, dass die Verteilung aufgehoben wird“ an und wählen Sie „Verteilung aufheben“. Danach klappt das Umhängen.

Beispiele

Beispiel: Max Mustermann hat im Datensatz die IBAN XX00 FAKE 0000 0000 01. Seine Zahlung vom 03.02.2026 über 17,00 € kommt von dieser IBAN. Beim Import ordnet KASSIVO sie ihm zu. Er taucht nie in „Unklar“ auf.

Beispiel: Zahlung von Dritten. Die Mutter von Erika Musterfrau überweist deren Beitrag von XX00 FAKE 0000 0000 02. KASSIVO kennt die IBAN nicht, die Zahlung steht in „Unklar“. Sie wählen Erika Musterfrau, lassen „Absender merken“ angehakt und wählen „Zuordnen“. Ab jetzt landen Überweisungen dieser IBAN automatisch bei Erika.

Beispiel: Geschwister. Dieselbe Mutter zahlt später auch für Hans Musterfrau, von derselben IBAN, die bei Erika gemerkt ist. KASSIVO ordnet die Zahlung vom 05.02.2026 über 17,00 € deshalb Erika zu. Deckt sie genau Erikas Beitrag für den Februar, bestätigt KASSIVO sie sogar selbst. Dann hängen Sie sie so auf Hans um:

  1. Öffnen Sie Buchungen, suchen Sie die Zahlung und wählen Sie „Verteilung“. Haken Sie „Ich bestätige, dass die Verteilung aufgehoben wird“ an und wählen Sie „Verteilung aufheben“. Ohne diesen Schritt meldet KASSIVO beim Umhängen: „… hat bestätigte Verteilung: Verteilung zuerst aufheben“.
  2. Wählen Sie in „Buchungen“ in der Spalte „Mitglied“ Hans Musterfrau und dann „Zuordnen“. Beachten Sie „Absender merken“: Die IBAN ist schon für Erika gemerkt. Ist das Häkchen gesetzt, gehört sie danach zwei Mitgliedern, und KASSIVO meldet: „Zugeordnet. Die Absender-IBAN gehört mehreren Mitgliedern und wird künftig nicht automatisch zugeordnet.“ Jede weitere Zahlung dieser IBAN bleibt in „Unklar“, bis Sie sie von Hand zuordnen.
  3. KASSIVO schlägt für Hans einen neuen Vorschlag vor. Es nimmt dabei Hans' frühesten Monat mit Fehlbetrag, nicht den Buchungsmonat. Hat Hans noch den Januar offen, steht dort der Januar statt des Februars. Prüfen Sie den Monat auf der Seite „Verteilung“ und ändern Sie ihn bei Bedarf.
  4. Wählen Sie „Verteilung bestätigen“.

Gut zu wissen

  • Absender merken ist in „Unklar“ vorangehakt, in „Buchungen“ nicht.
  • Zahlt jemand für mehrere Mitglieder, nehmen Sie bei den Zahlungen das Häkchen „Absender merken“ heraus und ordnen jede Zahlung von Hand zu. Dann gibt es keinen falschen automatischen Treffer. Trägt dieselbe IBAN bei zwei Mitgliedern im Datensatz, ist sie ebenfalls mehrdeutig.
  • Eine gemerkte IBAN lässt sich in dieser Version nicht wieder vergessen. Eine falsche Zuordnung korrigieren Sie bei der Zahlung (siehe oben). Die Zahlungen derselben IBAN danach ordnet KASSIVO weiter dem gemerkten Mitglied zu, bis die IBAN durch eine zweite Zuordnung mit „Absender merken“ mehrdeutig wird.
  • Eine falsch gemerkte IBAN wird nie für das richtige Mitglied neu gelernt. Ordnen Sie die Zahlung dem richtigen Mitglied mit „Absender merken“ zu, gehört die IBAN danach zwei Mitgliedern und ist mehrdeutig. Sie wird dann nie mehr automatisch zugeordnet. Auch ein weiteres Zuordnen ändert das nicht. Nehmen Sie in dem Fall „Absender merken“ heraus und ordnen Sie jede Zahlung von Hand zu.
  • Ausgetretene Mitglieder werden für Zahlungen nach dem Austrittsdatum nicht automatisch zugeordnet. Von Hand geht es weiterhin. Im Auswahlfeld steht „(ausgetreten)“ beim Namen.
  • Die Liste „Buchungen“ zeigt 100 Buchungen je Seite. Mit „Weiter“ und „Zurück“ blättern Sie.
  • Eine Zuordnung ändert nie die Buchung selbst, nur ihr Mitglied und ihre Verteilung.
  • Beim Umhängen auf ein anderes Mitglied verwirft KASSIVO die Vorschläge des alten Mitglieds und rechnet neu. Bestätigte Verteilungen sperren das Umhängen, bis Sie sie aufheben.

Achtung: Zahlungseingänge ohne Absender-IBAN (zum Beispiel Bareinzahlungen) und Sammelbuchungen werden nie automatisch zugeordnet. Sie stehen immer in „Unklar“.

Achtung: „— keins —“ setzt eine Zahlung nur vorübergehend auf „Unklar“. Die gemerkte IBAN bleibt, und KASSIVO ordnet die Zahlung wieder zu, sobald Sie „Unklare automatisch zuordnen“ wählen oder bei einer anderen Zahlung derselben IBAN „Absender merken“ benutzen. Wollen Sie die Zahlung dauerhaft in „Unklar“ lassen, benutzen Sie „Unklare automatisch zuordnen“ danach nicht, oder Sie nehmen hin, dass sie wieder zugeordnet wird.

Tipp: Tragen Sie die IBAN beim Anlegen des Mitglieds ein. Dann ordnet KASSIVO schon den ersten Import richtig zu.
