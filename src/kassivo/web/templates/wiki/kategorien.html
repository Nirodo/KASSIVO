Wofür ist das?

Kategorien sortieren Einnahmen und Ausgaben für den Report, zum Beispiel „Beiträge“ oder „Hauptverein“. Ab dieser Version ist eine Kategorie ein Konto: Ertragskonten für Eingänge, Aufwandskonten für Ausgänge. Wer eine Kategorie setzt, verbucht die Zahlung auf dieses Konto. Regeln weisen Buchungen automatisch einem Konto zu. Ohne Konto erscheint eine Buchung als „Ohne Kategorie“.

KASSIVO startet mit einem Kontenplan, darin unter anderem Beiträge, Spenden, Zinsen und Sonstige Einnahmen (Ertrag) sowie Hauptverein, Bankgebühren und Sonstige Ausgaben (Aufwand). Die frühere Kategorie „Sonstiges“ heißt jetzt „Sonstige Einnahmen“ und „Sonstige Ausgaben“.

So geht's

Konten

Konten legen Sie im Kontenplan an. Die Seite Regeln (/categories) zeigt die Ertrags- und Aufwandskonten mit ihren Regeln.

Regel anlegen

  1. Wählen Sie unter „Regel anlegen“ das „Konto (Kategorie)“, auf das die Regel bucht.
  2. Wählen Sie das „Feld“: „Verwendungszweck“, „Name der Gegenpartei“ oder „IBAN der Gegenpartei“.
  3. Tragen Sie bei „Enthält (Pflicht)“ den Text ein, der im Feld vorkommen muss.
  4. Setzen Sie bei Bedarf die „Priorität“, einen „Mindestbetrag“ und einen „Höchstbetrag“.
  5. Wählen Sie „Regel anlegen“.

Regeln auf vorhandene Buchungen anwenden

  1. Gehen Sie zum Abschnitt „Regeln auf alle Buchungen anwenden“.
  2. Lassen Sie „Gesetzte Kategorien überschreiben“ leer, wenn nur Buchungen ohne Kategorie eine bekommen sollen.
  3. Wählen Sie „Regeln anwenden“. KASSIVO meldet zum Beispiel: „Regeln angewendet: 3 Buchungen geändert.“

Eine Buchung von Hand kategorisieren

In Buchungen steht in der Spalte „Kategorie“ eine Auswahl. Wählen Sie die Kategorie und dann „Setzen“. Mit „Ohne Kategorie“ nehmen Sie die Kategorie wieder weg. Der Filter oberhalb der Liste (Jahr, „Kategorie“ mit der Wahl „Ohne Kategorie“, „Art“ und Suchtext) findet Buchungen wieder. Wählen Sie „Filtern“, um ihn anzuwenden.

So arbeiten Regeln

  • Enthält: Die Regel trifft, wenn das Feld den Text irgendwo enthält. Groß- und Kleinschreibung spielen keine Rolle. Bei der IBAN werden Leerzeichen ignoriert.
  • Priorität: Die kleinere Zahl gewinnt. KASSIVO prüft die Regeln in dieser Reihenfolge und nimmt die erste, die passt. Haben zwei Regeln dieselbe Zahl, gilt die ältere. Erlaubt sind 0 bis 10000, ohne Angabe gilt 100.
  • Art des Kontos: Eine Regel auf ein Ertragskonto bucht nur Zahlungseingänge, eine Regel auf ein Aufwandskonto nur Ausgaben. Eine Regel auf ein ausgeblendetes Konto ruht.
  • Betragsgrenzen: „Mindestbetrag“ und „Höchstbetrag“ gelten für den Betrag ohne Vorzeichen. Eine Ausgabe von −40,00 € hat die Größe 40,00 €. Beide Grenzen sind optional, erlaubt sind 0,00 € bis 100.000,00 €. Der Punkt ist das Tausendertrennzeichen und das Komma trennt die Cent: 1.500 gilt als 1.500,00 €, 17.00 lehnt KASSIVO ab (richtig: 17,00).

Beispiele

Beispiel: Zinsen der Bank. Sie legen für das Konto „Zinsen“ eine Regel an: Feld „Verwendungszweck“, Enthält „Zinsen für Guthaben“. Die Quartalsabrechnung der Bank (ohne Gegenpartei) bekommt beim Import die Kategorie „Zinsen“ und erscheint nie in „Unklar“, denn eine Zahlung mit einer anderen Kategorie als „Beiträge“ braucht kein Mitglied. Vorhandene Abrechnungen kategorisieren Sie mit „Regeln anwenden“ oder in Unklar mit „Als erledigt kategorisieren“.

Beispiel: Sie haben im Kontenplan das Aufwandskonto „Miete“ und legen eine Regel an: Feld „Verwendungszweck“, Enthält „Hallenmiete“. Eine Ausgabe mit dem Zweck „Hallenmiete März 2026“ bekommt beim nächsten Import die Kategorie „Miete“.

Beispiel: Zwei Regeln erfassen das Wort „Spende“. Regel A gibt „Sonstige Einnahmen“ mit Priorität 100, Regel B gibt „Spenden“ mit Priorität 10. Eine Buchung mit „Spende“ bekommt „Spenden“, denn 10 ist kleiner als 100.

Beispiel: Regel: Feld „Name der Gegenpartei“ enthält „Hauptverein Beispielstadt“, Kategorie „Hauptverein“, Höchstbetrag 500,00 €. Eine Überweisung über 300,00 € dorthin passt. Eine über 800,00 € nicht und bleibt unkategorisiert.

Gut zu wissen

  • Neue Importe: Regeln wirken beim Import automatisch auf die neuen Buchungen. Eine neue oder geänderte Regel ändert alte Buchungen erst, wenn Sie „Regeln anwenden“ wählen.
  • Beiträge: Ordnen Sie eine Zahlung einem Mitglied zu und hat sie noch keine Kategorie, setzt KASSIVO „Beiträge“. Eine vorhandene Kategorie bleibt.
  • Überschreiben: Mit „Gesetzte Kategorien überschreiben“ gilt eine passende Regel auch für Buchungen, die schon eine Kategorie haben. Dafür müssen Sie zusätzlich „Ich bestätige das Überschreiben (nur nötig beim Überschreiben)“ anhaken. Sonst lehnt KASSIVO ab („Zum Überschreiben bitte ausdrücklich bestätigen.“). Passt keine Regel, bleibt eine vorhandene Kategorie stehen.
  • Reservierter Name: „Ohne Kategorie“ ist kein echter Name und lässt sich nicht als Konto anlegen.
  • Korrektur: Wählen Sie eine andere Kategorie, storniert KASSIVO die bisherige Verbuchung und bucht neu. Die gleiche Kategorie noch einmal ändert nichts.
  • In dieser Version lassen sich Regeln nur anlegen, nicht ändern oder löschen.

Achtung: „Regeln anwenden“ mit Überschreiben kann Kategorien ersetzen, die Sie von Hand gesetzt haben. Legen Sie vorher eine Sicherung an (Backup).
