Wofür ist das?

Diese Seite zeigt den Weg vom ersten Start bis zum fertigen Beitragsüberblick. Wer die Schritte in dieser Reihenfolge geht, vermeidet die häufigsten Fehler.

Der erste Start

Unter Windows starten Sie KASSIVO per Doppelklick auf start.bat im Projektordner: Die Datei startet den Server und öffnet den Browser. Von Hand geht es im Projektordner mit python -m kassivo. Die Konsole zeigt zwei Zeilen: Datenbank: … und Sicherungen: … mit den vollständigen Pfaden. Liegt die Datenbank in einem Cloud-Ordner (OneDrive, Dropbox, Google Drive, iCloud), steht dort zusätzlich eine Warnung. Danach öffnen Sie im Browser http://127.0.0.1:8000. Oben stehen die fünf Bereiche Übersicht, Mitglieder, Zahlungen, Auswertung und Einstellungen. Die Adresse ohne Pfad zeigt die Startseite im Bereich Übersicht.

Beim ersten Start ist KASSIVO leer. Die Übersicht meldet „Noch keine Daten“ und nennt die ersten Schritte. KASSIVO legt die Datenbank beim ersten Aufruf selbst an und bringt Folgendes mit:

  • zwei Mitgliedsarten: Aktiv mit 17,00 € und Passiv mit 10,00 € pro Monat,
  • drei Kategorien: Beiträge (Einnahmen), Hauptverein (Ausgaben) und Sonstiges (beides).

Die Datenbank liegt standardmäßig unter Windows in %LOCALAPPDATA%\KASSIVO\kassivo.db, unter Linux und macOS in ~/.local/share/kassivo/kassivo.db. Mit der Umgebungsvariable KASSIVO_DB wählen Sie einen anderen Ort. Setzen Sie sie vor dem Start im selben Fenster, je nach Programm so:

  • Eingabeaufforderung (cmd): set KASSIVO_DB=D:\Kasse\kassivo.db
  • PowerShell: $env:KASSIVO_DB = "D:\Kasse\kassivo.db" (der cmd-Befehl set setzt in PowerShell keine Umgebungsvariable, KASSIVO startet dann ohne Fehlermeldung mit dem Standardpfad)

Die Variable gilt nur für dieses Fenster. Dauerhaft setzen Sie sie in cmd mit setx KASSIVO_DB "D:\Kasse\kassivo.db". Das wirkt erst in neuen Fenstern. Sonst startet ein späterer Start mit einer anderen Datenbank (siehe Fehlerbehebung, Frage 3).

So geht's

  1. Prüfungsstart festlegen. Öffnen Sie Einstellungen (/settings/fees), tragen Sie unter „Prüfungsstart (Monat)“ den ersten Monat ein, der geprüft werden soll (Format JJJJ-MM), und wählen Sie „Prüfungsstart speichern“. Solange er fehlt, zeigen Übersicht, Beitragsübersicht und Import einen Hinweis. Wählen Sie den ersten vollen Monat, den Ihr Kontoexport abdeckt. Mehr dazu unter Beiträge und Prüfungsstart.
  2. Mitglieder und Beiträge anlegen. Unter Mitglieder wählen Sie „Mitglied anlegen“. Prüfen Sie unter Einstellungen, ob die Beiträge stimmen, und ändern Sie sie bei Bedarf mit „Beitrag speichern“. Siehe Mitglieder.
  3. Kontoexport importieren. Erzeugen Sie im Online-Banking den Export „XML CAMT V8, gebuchte Umsätze“ und laden Sie ihn unter Import mit „Importieren“ hoch. Siehe Kontoexport importieren.
  4. „Unklar“ zuordnen. Zahlungen, die KASSIVO keinem Mitglied sicher zuordnen konnte, stehen unter Unklar. Wählen Sie das Mitglied, lassen Sie „Absender merken“ angehakt und wählen Sie „Zuordnen“. Siehe Zahlungen zuordnen.
  5. Ausnahmen prüfen. Eindeutige Zahlungen verteilt KASSIVO selbst auf die Beitragsmonate. Was es so verteilt hat, sehen Sie unter Automatisch verteilt. Nur echte Ausnahmen (zum Beispiel 20,00 € bei 17,00 € Beitrag) stehen unter „Offene Vorschläge“, mit dem Grund. Öffnen Sie dort je Zahlung „Verteilung“, prüfen Sie die Monate und wählen Sie „Verteilung bestätigen“. Siehe Verteilung auf Beitragsmonate.
  6. Ergebnis ansehen. Beiträge zeigt, wer bezahlt hat, Prognose was noch kommt, Reports das Jahr in Zahlen und Diagrammen.

Die Startseite „Heute zu tun“

Die Übersicht ist Ihr Ausgangspunkt. Sie ist nur zum Lesen: Das Öffnen ändert nichts. Oben steht der Knopf „Kontoauszug importieren“. Jede Zeile mit einer Zahl führt auf die Seite, auf der Sie diese Einträge sehen:

  • Unklare Zahlungen: die Zahlungseingänge unter Unklar, über alle Jahre.
  • Offene Vorschläge: Zahlungen, die auf Ihre Prüfung warten (Offene Vorschläge), über alle Jahre.
  • Überfällige Monatsbeiträge: die Anzahl der Zellen „Überfällig“ im Beitragsraster eines Jahres. Gezählt werden Monatsbeiträge, die Zahl der betroffenen Mitglieder steht darunter. Das laufende Jahr steht immer da, frühere Jahre nur, wenn dort etwas überfällig ist.
  • Automatisch verteilt (unter „Zur Kontrolle“): alle Zahlungen, die KASSIVO selbst verteilt hat (Automatisch verteilt, bei vielen Zahlungen auf mehreren Seiten).

Für den laufenden Monat sehen Sie, wie viele Mitglieder mit fälligem Beitrag bezahlt haben, wie viele offen sind und wie viele teilweise gezahlt haben. „Bezahlt … von … erwartet“ entspricht der Fußzeile des Beitragsrasters. „Einnahmen und Ausgaben“ zeigt dieselben Zahlen wie der Jahresreport. Der Saldo ist Einnahmen minus Ausgaben der Buchungen des Jahres, nicht der Kontostand.

Beispiele

Beispiel: Der Kontoexport beginnt am 15.03.2026. Frühere Zahlungen von März fehlen. Wählen Sie deshalb 2026-04 als Prüfungsstart. Würden Sie 2026-03 wählen, erschiene der März bei vielen Mitgliedern als überfällig, obwohl sie früher im Monat gezahlt haben. Zahlungen aus dem März, die im Export stehen, liegen vor dem Prüfungsstart. KASSIVO ordnet sie den Mitgliedern zu, verteilt sie aber nicht auf Monate (Näheres unter Beiträge und Prüfungsstart).

Beispiel: Max Mustermann (Art Aktiv, Eintritt 10.01.2026) zahlt ab 2026-02. Der Prüfungsstart ist 2026-02. Am 03.02.2026 geht 17,00 € von XX00 FAKE 0000 0000 01 ein. Steht diese IBAN in seinem Mitgliedsdatensatz, ordnet KASSIVO die Zahlung beim Import selbst zu und verteilt sie automatisch auf den Februar. Sie steht danach unter „Automatisch verteilt“.

Gut zu wissen

Achtung: Der Prüfungsstart ist die wichtigste Einstellung. Setzen Sie ihn vor dem ersten Import. Ändern Sie ihn später, berechnet KASSIVO alle automatischen Verteilungen und Vorschläge neu. Nur Verteilungen, die Sie selbst bestätigt oder zur Prüfung gestellt haben, bleiben unverändert.

Tipp: Legen Sie nach dem ersten Import eine Sicherung an (Backup). Dann haben Sie einen sauberen Stand, auf den Sie zurückgehen können.

  • KASSIVO verteilt eine Zahlung zuerst auf ihren Buchungsmonat, dann auf Rückstände, dann auf folgende Monate. Passt sie zu ganzen Monatsbeiträgen oder ist sie eine einzelne Teilzahlung, bestätigt KASSIVO sie selbst. Jede automatische Verteilung können Sie mit „Rückgängig“ zurücknehmen.
  • KASSIVO liest nur Dateien ein. Es fragt kein Bankkonto ab.
  • Alle Daten bleiben auf Ihrem Rechner. Siehe Datenschutz und Sicherheit.
