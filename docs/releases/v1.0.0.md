# KASSIVO 1.0.0

Erstes Release. KASSIVO ist eine lokale Anwendung zur Verwaltung einer Gruppenkasse für eine Person an einem PC. Sie läuft im Browser unter `http://127.0.0.1:8000` und speichert alles in einer lokalen SQLite-Datei.

## Funktionen

- **Mitglieder** mit Mitgliedsart Aktiv oder Passiv, Eintritt, Austritt und Stammdaten.
- **Beiträge** pro Mitgliedsart mit Gültigkeitsmonat. Eine Änderung wirkt erst ab dem gewählten Monat, frühere Monate bleiben unverändert.
- **Import von Kontoumsätzen** aus dem Online-Banking (Format `XML CAMT V8, gebuchte Umsätze`, als ZIP mit Tagesdateien oder als einzelne XML-Datei). Doppelte Buchungen werden erkannt, ein mehrfacher Import ist sicher.
- **Zuordnung zu Mitgliedern** mit Lernen der Absender-IBAN, Liste "Unklar" und Schutz bei Geschwistern, die über dieselbe IBAN bezahlt werden.
- **Verteilung auf Beitragsmonate**: Eine Zahlung wird nur dann automatisch bestätigt, wenn sie genau den frühesten offenen Monat deckt und im selben Monat gebucht wurde. Alles andere ist ein Vorschlag, den du bestätigst.
- **Kategorien und feste Regeln** für Einnahmen und Ausgaben.
- **Beitragsübersicht** pro Jahr (Bezahlt, Teilweise, Offen, Überfällig), **Zahlungshistorie** pro Mitglied und **Prognose** der noch offenen Beiträge.
- **Jahresreport** mit Torten- und Balkendiagrammen und passenden Tabellen.
- **Backup** der Datenbank per Knopfdruck.
- **Wiki im Programm** (`/wiki`) mit Erklärungen zu allen Funktionen, Beispielen und Fehlerbehebung.

## Installation und Start

```
python -m venv .venv
.venv\Scripts\activate
pip install -e .[dev]
python -m kassivo
```

Die Datenbank liegt standardmäßig unter `%LOCALAPPDATA%\KASSIVO\kassivo.db`, nicht im Projektordner. Mit der Umgebungsvariable `KASSIVO_DB` lässt sich ein anderer Ort wählen. Details stehen im README und im Wiki.

## Datenschutz

Alle Daten bleiben lokal. Der Server lauscht nur auf `127.0.0.1`. Es werden keine Bankzugangsdaten gespeichert, der Import liest nur Dateien. Echte Bankdateien und Datenbanken gehören nicht in Git; die `.gitignore` schützt die üblichen Dateien.

## Bekannte Einschränkungen

- Kontoumsätze kommen nur per Datei-Import (`camt.052.001.08`). Eine direkte Bankabfrage (FinTS, finAPI) und ein Adapter für die C24 Bank gibt es noch nicht.
- Es gibt keine Möglichkeit, Buchungen von Hand einzutragen (zum Beispiel Barzahlungen). Nur der Import erzeugt Buchungen.
- Ein Eintrag mit 0,00 € im Export bricht den Import der ganzen Datei ab.
- Kategorien und Regeln lassen sich anlegen, aber nicht ändern oder löschen.
- Eine gelernte oder mehrdeutige Absender-IBAN lässt sich nicht wieder vergessen.
- Eintritt und "Zahlt ab Monat" lassen sich nach dem Anlegen nicht ändern.
- Keine Anmeldung und nur ein Nutzer. Wer Zugriff auf den PC und den Browser hat, sieht alle Daten.
- Die Diagramme brauchen JavaScript im Browser. Die Darstellung im Browser (Diagramme, Dunkelmodus, Handybreite) wurde nicht automatisch getestet.
- Getestet wurde nur mit Python 3.15. Erklärt ist `>=3.10`.

Weitere kleinere Punkte stehen als Issues im Repository.
