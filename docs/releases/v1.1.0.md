# KASSIVO 1.1.0

Kleines Funktions-Release.

## Neu

- **`start.bat`**: Doppelklick im Projektordner startet KASSIVO mit der virtuellen Umgebung `.venv` und öffnet den Browser auf `http://127.0.0.1:8000`. Fehlt `.venv`, zeigt die Datei die nötigen Installationsschritte. Mit `start.bat nobrowser` startet nur der Server. In einer Eingabeaufforderung oder PowerShell heißt der Aufruf `.\start.bat`.
- `.gitattributes`: Batch-Dateien behalten die Windows-Zeilenenden (CRLF).
- README und Wiki ("Erste Schritte") beschreiben den neuen Start.

Issue: #22, Pull Request: #23.

## Unverändert

Funktionen, Datenbankformat und Standard-Datenbankpfad (`%LOCALAPPDATA%\KASSIVO\kassivo.db`) bleiben wie in 1.0.0. Ein Update braucht keine Migration. Die bekannten Einschränkungen aus 1.0.0 gelten weiter und stehen als Issues im Repository.
