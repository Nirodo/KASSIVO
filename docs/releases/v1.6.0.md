# KASSIVO 1.6.0

## Neu

- **Beiträge direkt in der Tabelle bestätigen** (#56): Ein Klick auf eine Zelle im Beitragsraster zeigt die Zahlungen dieses Monats mit **Bestätigen**, **Ändern** und, bei automatisch verteilten, **Rückgängig**. Umfasst eine Zahlung mehrere Monate, steht das dabei; Bestätigen gilt für alle.
- **Alle Vorschläge bestätigen:** zeigt vorher eine Liste zum Abwählen. Bestätigt wird nur, was unverändert ist; Übersprungenes wird mit Grund gemeldet. Die Sammelbestätigung überzahlt keinen Monat. Beim Einzelbestätigen warnt KASSIVO vorher, falls ein Monat danach überzahlt wäre.

## Besser

- Beitragsraster und Startseite sind deutlich schneller (#49).

## Bekannte Einschränkungen

- Bricht die Sammelbestätigung durch einen Fehler ab, bleiben die bis dahin bestätigten Zahlungen bestätigt. Prüfe dann das Raster. Weitere kleine Punkte: #72.

Die Datenbank wird nicht umgestellt (weiter Schema 3).
