# KASSIVO 1.5.0

## Neu

- **Neu anfangen** (#65): Unter **Einstellungen → Neu anfangen** löschst du die Datenbank und beginnst wie beim ersten Start. Die Seite zeigt vorher, was verloren geht, und verlangt die Eingabe von `LÖSCHEN`. Davor legt KASSIVO automatisch eine Sicherheitskopie an; schlägt sie fehl, wird nichts gelöscht. Zurück geht es über **Backup → Vorhandene Sicherungen → Wiederherstellen**.
- Das Aufräumen alter Sicherungen löscht nie die letzte Sicherung, die noch Daten enthält.

## Beachten

- "Neu anfangen" entfernt **alles**, auch Mitglieder und Einstellungen. Die Wahl, nur Buchungen zu löschen und Stammdaten zu behalten, folgt später (#67).
- Vorhandene Sicherungen bleiben erhalten und enthalten weiterhin Namen und IBANs.

Die Datenbank wird nicht umgestellt (weiter Schema 3).
